# Product Catalog

A simple website that displays a product catalog in PDF format.

## Features

- Clean, modern interface with gradient background
- Embedded PDF viewer for seamless catalog browsing
- Responsive design that works on desktop and mobile devices
- Sample product catalog included

## How to Use

1. Open `index.html` in your web browser, or
2. Serve the directory with a local web server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000` in your browser

## Files

- `index.html` - Main webpage with PDF viewer
- `styles.css` - Styling for the webpage
- `catalog.pdf` - Sample product catalog PDF

## Customization

To display your own PDF:
1. Replace `catalog.pdf` with your own PDF file
2. Update the filename in `index.html` if you use a different name
3. Modify the header text in `index.html` as needed
